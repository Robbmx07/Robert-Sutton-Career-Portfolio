Phase 04: Final alignment construction

The datum reference frame, built in the order it implies, not the order that's easiest.

  1. Level, rotate, then translateLevel to the primary datum, rotate to the secondary, then set origin to the tertiary. Never translate before the part is fully leveled and rotated.
    WatchTranslating first moves your origin out from under you. Redo the sequence; don't patch around it.
  2. Name it to the printName the alignment to match the datum callout (for example "ABC") so it traces back to the drawing without opening it.
  3. Keep the rough alignment unless the fixture earns its removalOnly drop the manual pre-alignment when the fixture is permanent, constrains all six degrees of freedom, and lands in the same spot on the table every run.
    WatchV-blocks, stand-offs, and adjustable stops don't install in the same place twice. Keep the manual step and document the fixture placement instead.
  4. Build secondary alignments deliberatelyFor a pattern on a different face, build and name a separate alignment and switch into it only for the features that need it.

From phase 00: a stale probe qualification is the most common reason a program measures perfectly in the office and fails on the floor.

Vectors & CAD Surface Normals

From the PC-DMIS Master Reference and the CAD Surface Normals procedure.

Master Reference · §02CAD Normals · phases 1–5

The vector is a surface normal

More CMM programs go wrong from a flipped vector than from almost anything else. For a plane, circle, or cylinder, I, J, and K describe the direction perpendicular to the surface. They are direction cosines to X, Y, and Z, and together they always form a unit vector. They are tied to the 3D coordinate system, not the 2D workplane.

The part-to-probe rule

The vector points from the surface toward the direction the probe came from. If the probe drives down in −Z to touch a top face, the vector points back up: 0, 0, 1.

Surface facesProbe approaches fromVector
UpAbove (moving −Z)0, 0, 1
DownBelow (moving +Z)0, 0, −1
Toward +X+X side (moving −X)1, 0, 0
Toward −X−X side (moving +X)−1, 0, 0
Toward +Y+Y side (moving −Y)0, 1, 0
Toward −Y−Y side (moving +Y)0, −1, 0

For a feature that isn't square to an axis, don't hand-calculate direction cosines. Build a temporary alignment that squares the feature to a major axis, use the simple ±1 vector, and let the alignment handle the real orientation.

When the CAD model itself is wrong

Inverted surface normals in the CAD model give auto features the wrong vector before a single hit is taken. The fix is a short, repeatable check:

  1. Turn off two-sided lightingIn solid view, uncheck two-sided lighting. Surfaces whose normals point inward shade darker than the rest of the model, so bad geometry shows up at a glance.
  2. Show the vectorsOpen the CAD Vectors tool and display the normal arrows on the active surfaces.
  3. Flip or fixFlip a block of surfaces you've identified by eye, or let PC-DMIS fix the selection so every normal points outward.
  4. Save before building featuresSave the program so the corrected vectors are in place before any feature is generated.

Read Point Alignment Guide

Establishing a safe starting alignment in PC-DMIS, from CAD setup through execution and verification.

PC-DMIS Field Guide12 sections · checklist

Critical concept: a single read point constrains translation only. It removes 3 of the part's 6 degrees of freedom and does not level or rotate the part. It is a bootstrap alignment, never a reporting alignment.

What it's for

The operator touches one known location, and PC-DMIS offsets the coordinate system so the CAD nominal and the physical point agree. That gets DCC moves and collision avoidance somewhere safe to start. The real datum features are then measured under DCC, and the production alignment is built from them.

The commands

' Manual read point, with room for hand positioning
MODE/MAN
PREHIT/0.25
RETRACT/0.25
CHECK/0.25,1
PNT_READ =FEAT/POINT,CARTESIAN
   THEO/<0,0,0>,<0,0,1>
   ACTL/<Xm,Ym,Zm>,<0,0,1>
READPOINT/

' Translation-only bootstrap alignment
ALN_READ =ALIGNMENT/START,RECALL:STARTUP,LIST=YES
ALIGNMENT/TRANS,XAXIS,PNT_READ
ALIGNMENT/TRANS,YAXIS,PNT_READ
ALIGNMENT/TRANS,ZAXIS,PNT_READ
ALIGNMENT/END

COMMENT/OPER,NO,FULL SCREEN=YES,AUTO-CONTINUE=NO,
  VERIFY CLEARANCE ON FIRST DCC MOVES
MODE/DCC

Report & Label Template Kit

Four PC-DMIS report layouts and a working guide to the template editors behind them.

4 templates · 9 sectionsExcerpt: balloon & Form 3

Balloon numbers in the report

A stock PC-DMIS report numbers rows by its own running count. Printing the drawing's balloon number instead makes the report read straight across to the ballooned print. Each characteristic's balloon is stored in a variable just before its dimension, and the label template reads it back row by row.

ASSIGN/V1[1]=15      $$ X  → balloon 15
ASSIGN/V1[2]=30      $$ Y  → balloon 30
ASSIGN/V1[3]=75      $$ D  → balloon 75
DIM LOC1= LOCATION OF CIRCLE CIR1 ...

Label cell expression:
=INT(VARIABLE("V1["+N+"]",ID:N))

Form 3 layout

Built on the balloon report, so the characteristic number is the balloon. Failures print in red, and the Accept column is computed from the out-of-tolerance value.

SOP-4 Control of Nonconforming Product

From the ISO 9001 QMS I wrote for a local machine shop. Company name changed to a fictional one.

Harrow Creek Machine (fictional)ISO 9001:2015 Ref: 8.7Rev 0

1.0 Purpose

To ensure product that does not conform to requirements is identified and controlled to prevent its unintended use or delivery.

2.0 Scope

Nonconforming raw material, work-in-process, and finished product identified at receiving, in-process, final inspection, or after delivery (customer complaint/return).

4.0 Procedure

  1. Tag and segregateNonconforming product is tagged and physically segregated in a designated hold area to prevent unintended use or mixing with conforming product.
  2. Open an NCARA Nonconformance & Corrective Action Report is opened in the ERP system describing the nonconformity (see SOP-2, Record Control).
  3. DispositionThe Quality Manager determines disposition: rework, repair, use-as-is, scrap, or return to supplier. Use-as-is dispositions affecting fit, form, or function require customer concession where required by contract.
  4. Re-inspectReworked or repaired product is re-inspected to verify conformity before release.
  5. Notify the customerIf nonconforming product has already been delivered, or a concession is required by contract, the customer is notified.
  6. Trend the dataNonconformance data is reviewed periodically for trends, feeding into Corrective Action (SOP-5) and Management Review (SOP-8).

Design choice: the NCAR lives in the shop's existing ERP system, so nonconformance and corrective action records are traceable by job number without a separate paper form.
